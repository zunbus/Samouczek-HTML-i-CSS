Podstawowa struktura pliku HTML

Każdy dokument HTML składa się z kilku podstawowych elementów, które określają strukturę strony i jej metadane. Prawidłowy układ pliku pomaga przeglądarce zrozumieć zawartość oraz poprawnie wyświetlić stronę.

1. Deklaracja dokumentu

Na początku pliku umieszczamy deklarację <!DOCTYPE html>, która informuje przeglądarkę, że dokument jest napisany w HTML5.

2. Element <html>

Zawiera cały dokument. Atrybut lang="pl" określa język strony i jest ważny dla dostępności.

3. Sekcja <head>

Wewnątrz <head> umieszczamy metadane dokumentu: tytuł, kodowanie, ustawienia widoku, styl i inne informacje, które nie są wyświetlane bezpośrednio.

4. Sekcja <body>

Sekcja <body> zawiera treść widoczną dla użytkownika: nagłówki, akapity, obrazy, linki oraz inne elementy strony.

Przykład podstawowej struktury

Kod

<!DOCTYPE html>
<html lang="pl">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Tytuł strony</title>
</head>
<body>
    <h1>Witaj w HTML</h1>
    <p>To jest podstawowa struktura dokumentu HTML.</p>
</body>
</html>

Taki szkielet jest najprostszym i jednocześnie zalecanym sposobem rozpoczęcia tworzenia strony HTML. W kolejnych plikach poznasz dodatkowe elementy i możliwości, jakie oferuje HTML.
