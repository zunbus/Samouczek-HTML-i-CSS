Listy

Listy w HTML służą do przedstawiania zbiorów elementów w czytelny i uporządkowany sposób. Najczęściej używa się list nienumerowanych, numerowanych oraz definicji.

<ul>

<ul> tworzy listę z punktami oznaczonymi symbolami. Każdy element listy musi znajdować się w <li>.

Kod

<ul>
  <li>Jabłka</li>
  <li>Banany</li>
  <li>Czereśnie</li>
</ul>

Wynik

  • Jabłka
  • Banany
  • Czereśnie

<ol>

<ol> tworzy listę numerowaną, idealną do instrukcji lub kolejnych kroków. Liczby są dodawane automatycznie przez przeglądarkę.

Kod

<ol>
  <li>Włącz komputer</li>
  <li>Otwórz przeglądarkę</li>
  <li>Odwiedź stronę</li>
</ol>

Wynik

  1. Włącz komputer
  2. Otwórz przeglądarkę
  3. Odwiedź stronę

<dl>

<dl> to lista definicji. Zawiera pary <dt> (termin) i <dd> (opis).

Kod

<dl>
  <dt>HTML</dt>
  <dd>Język znaczników służący do tworzenia stron internetowych.</dd>
  <dt>CSS</dt>
  <dd>Stylizacja wyglądu elementów HTML.</dd>
</dl>

Wynik

HTML
Język znaczników służący do tworzenia stron internetowych.
CSS
Stylizacja wyglądu elementów HTML.

Listy w HTML to proste i czytelne narzędzie do organizowania treści. Warto używać odpowiedniego typu listy zgodnie z przeznaczeniem.
