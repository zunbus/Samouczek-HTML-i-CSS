Menu Poziome

Menu poziome to nawigacja ustawiona w jednym wierszu. Często używa się do niego listy <ul> z elementami <li> i linkami <a>.

Jak zrobić menu poziome?

Najłatwiej utworzyć listę i zmienić domyślne wyświetlanie elementów <li>. Dwa popularne sposoby to display: inline-block oraz display: flex.

Kod

<nav>
      <ul>
        <li><a href="#">Home</a></li>
        <li><a href="#">O nas</a></li>
        <li><a href="#">Kontakt</a></li>
      </ul>
</nav>


nav ul {
  display: flex;
  gap: 1rem;
  list-style: none;
  padding: 0;
  margin: 0;
}

nav ul li a {
  text-decoration: none;
  color: inherit;
  padding: 0.5rem 1rem;
}

nav ul li a:hover{
  background-color: #125d92;
}

Wynik

  • Home
  • O nas
  • Kontakt

Zalety menu poziomego

  • Przejrzysta nawigacja dla stron o niewielu elementach.
  • Dobrze wygląda w nagłówku strony i na dużych ekranach.
  • Łatwe do zrealizowania przy pomocy CSS.

Wady menu poziomego

  • Może zajmować dużo miejsca przy wielu pozycjach.
  • Na mniejszych ekranach wymaga responsywnej zmiany układu.
  • Linki o długich nazwach mogą się nie mieścić w jednym wierszu.

Praktyczne uwagi

Warto użyć semantycznego <nav> oraz usunąć punktor listy przy pomocy list-style: none. Dla lepszej dostępności dobrze jest dodać czytelny odstęp i kontrast linków.
