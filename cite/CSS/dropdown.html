Menu rozwijalne

Menu rozwijalne (dropdown menu) to rodzaj nawigacji, w której dodatkowe opcje pojawiają się po najechaniu kursorem lub kliknięciu na element główny. Tego typu menu pozwala zaoszczędzić miejsce i uporządkować większą liczbę linków.

Jak działa menu rozwijalne?

Najczęściej wykorzystuje się zagnieżdżone listy <ul>. Główne elementy menu zawierają kolejne listy, które są ukrywane za pomocą CSS i wyświetlane dopiero po najechaniu na rodzica.

Kod

<ul class="dropdown-menu">
    <li>
        <a href="#">Pole 1</a>
        <ul>
            <li><a href="#">Pole 1.1</a></li>
            <li><a href="#">Pole 1.2</a></li>
        </ul>
    </li>

    <li>
        <a href="#">Pole 2</a>
        <ul>
            <li><a href="#">Pole 2.1</a></li>
            <li><a href="#">Pole 2.2</a></li>
        </ul>
    </li>
</ul>
.dropdown-menu-demo,
.dropdown-menu-demo ul {
    list-style: none;
    margin: 0;
    padding: 0;
}

.dropdown-menu-demo li {
    position: relative;
    width: 140px;
}

.dropdown-menu-demo a {
    display: block;
    padding: 10px;
    text-decoration: none;
    background: #c5ffb7;
    border: 1px solid #97ff97;
    color: black;
}

.dropdown-menu-demo ul {
    display: none;
    position: absolute;
    left: 140px;
    top: 0;
}

.dropdown-menu-demo ul a {
    background: #97ff97;
}

.dropdown-menu-demo li:hover > ul {
    display: block;
}

Zalety

  • Pozwala uporządkować dużą liczbę linków.
  • Oszczędza miejsce na stronie.
  • Ułatwia tworzenie wielopoziomowej nawigacji.

Wady

  • Na urządzeniach mobilnych hover może działać inaczej.
  • Zbyt rozbudowane menu może być trudne w obsłudze.
  • Niepoprawne pozycjonowanie może powodować nakładanie elementów.

Porady praktyczne

  • Stosuj krótkie i czytelne nazwy sekcji.
  • Dodaj efekty przejścia (transition) dla płynniejszej animacji.
  • Na urządzeniach mobilnych rozważ rozwijanie po kliknięciu zamiast hover.

Menu rozwijalne jest jednym z najczęściej używanych elementów nawigacyjnych w nowoczesnych stronach internetowych. Dzięki HTML i CSS można stworzyć je bez użycia JavaScriptu.
