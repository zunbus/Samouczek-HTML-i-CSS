Układy

Układ strony określa rozmieszczenie elementów takich jak nagłówek, menu, treść oraz stopka. W nowoczesnym CSS najczęściej wykorzystuje się flex lub grid do budowania układów kolumnowych.

Najpopularniejsze układy

  • 1 kolumna – prosty układ z jedną główną treścią.
  • 2 kolumny – treść + panel boczny (sidebar).
  • 3 kolumny – dwa panele boczne i główna zawartość.

Układ jednokolumnowy

Najprostszy układ strony. Świetnie sprawdza się na urządzeniach mobilnych oraz blogach.

Kod

<div class="layout">
    <header>Header</header>

    <main>
        Główna treść strony
    </main>

    <footer>Footer</footer>
</div>

.layout{
  display:flex;
  flex-direction:column;
  gap:10px;
}

header, main, footer{
  padding:20px;
}

header{
    background:#6fa8dc;
}

main{
  background:#f4f4f4;
}

footer{
  background:#999;
}

Wynik

Header
Główna treść strony
Footer

Układ dwukolumnowy

Układ dwukolumnowy często zawiera główną treść oraz boczny panel z menu, reklamami lub dodatkowymi informacjami.

Kod

<div class="layout">

    <header>Header</header>

    <div class="container">
        <main>Treść</main>
        <aside>Sidebar</aside>
    </div>

    <footer>Footer</footer>

</div>
            
.container{
    display:flex;
    gap:10px;
}

main{
    flex:3;
}

aside{
    flex:1;
}

Wynik

Header
Główna treść
Sidebar
Footer

Układ trójkolumnowy

Układ trójkolumnowy umożliwia dodanie dwóch paneli bocznych po obu stronach głównej treści.

Kod

<div class="layout">

    <header>Header</header>

    <div class="container">

        <aside>Lewe menu</aside>

        <main>Treść</main>

        <aside>Prawe menu</aside>

    </div>

    <footer>Footer</footer>

</div>
            
.container{
    display:flex;
    gap:10px;
}

aside{
    flex:1;
}

main{
    flex:2;
}

Wynik

Header
Lewe menu
Główna treść
Prawe menu
Footer

Dlaczego warto używać Flexbox?

Flexbox bardzo ułatwia tworzenie nowoczesnych układów stron. Dzięki niemu można łatwo ustawiać kolumny, wyrównywać elementy oraz tworzyć responsywne layouty działające na różnych urządzeniach.

Podsumowanie

  • 1 kolumna – prostota i czytelność.
  • 2 kolumny – najczęściej używany układ stron.
  • 3 kolumny – większa ilość informacji na ekranie.

Współczesne strony internetowe najczęściej buduje się przy użyciu flex lub grid, ponieważ zapewniają dużą kontrolę nad rozmieszczeniem elementów.
