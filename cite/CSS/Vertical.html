Menu pionowe

Menu pionowe to nawigacja ułożona w kolumnie. Najczęściej stosowane w bocznych panelach (sidebar) lub w aplikacjach, gdzie wymagana jest długa lista sekcji.

+

Jak zbudować menu pionowe?

Podstawą jest semantyczna lista <ul> z elementami <li> i linkami <a>. CSS sprawia, że linki zajmują całą szerokość wiersza, co poprawia klikalność.

Kod

<nav>
  <ul>
    <li><a href="#">Panel 1</a></li>
    <li><a href="#">Panel 2</a></li>
    <li><a href="#">Panel 3</a></li>
  </ul>
</nav>

nav ul {
  list-style: none;
  padding: 0;
  margin: 0;
  width: 200px;
}

nav a {
  display: block;
  padding: 0.75rem 1rem;
  text-decoration: none;
  color: inherit;
}

nav li { border-top: 1px solid #e0e0e0; }

Wynik

  • Panel 1
  • Panel 2
  • Panel 3

Zalety

  • Dobrze skaluje się przy wielu pozycjach nawigacyjnych.
  • Łatwiejsze do czytania i skanowania w pionie.
  • Może pełnić rolę trwale widocznego panelu bocznego.

Wady

  • Zajmuje wertykalną przestrzeń; może wymagać przewijania na małych ekranach.
  • Może zmniejszać przestrzeń treści głównej na wąskich widokach.

Porady praktyczne

  • Rozważ zastosowanie rozwijanego/zwijanego menu (accordion) dla długich list.
  • Na urządzeniach mobilnych często lepiej przełączyć menu pionowe na hamburger / menu wysuwane.
  • Zadbaj o dostępność: używaj porządnych kontrastów, focus styles i semantycznych znaczników.

Pamiętaj, że układ można łatwo zmienić za pomocą CSS (np. flex-direction), dzięki czemu ten sam kod HTML może działać zarówno jako menu pionowe, jak i poziome.
