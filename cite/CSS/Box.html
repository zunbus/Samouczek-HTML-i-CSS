Pudełkowy model CSS

W CSS każdy element jest traktowany jak pudełko. Pudełkowy model składa się z zawartości, paddingu, obramowania i marginesu.

Co zawiera pudełko?

Pudełko składa się z:

  • zawartości (content)
  • wewnętrznego odstępu (padding)
  • obramowania (border)
  • zewnętrznego odstępu (margin)

padding

Padding to wewnętrzny odstęp między zawartością a obramowaniem elementu.

Kod

div {
  padding: 20px;
  border: 1px solid #125d92;
}

Wynik

To pudełko ma padding 20px.

border

Border to obramowanie otaczające padding i zawartość.

Kod

div {
  border: 4px dashed #1572B6;
  padding: 10px;
}

Wynik

Obramowanie jest częścią pudełka wokół zawartości.

margin

Margin to zewnętrzny odstęp między pudełkami elementów.

Kod

div {
  margin: 20px;
  padding: 10px;
  border: 1px solid #125d92;
}

Wynik

Ten element ma zewnętrzny margines 20px.

width i height

Właściwości width i height określają rozmiar zawartości, a nie całego pudełka, jeśli nie użyto box-sizing.

Kod

div {
  width: 300px;
  height: 80px;
  padding: 10px;
  border: 2px solid #125d92;
}

Wynik

Rozmiar zawartości wynosi 300x80px; padding i border dodają się do całości.

box-sizing

box-sizing zmienia sposób obliczania szerokości i wysokości. Wartość border-box sprawia, że padding i border mieszczą się w zadanym rozmiarze.

Kod

div {
  box-sizing: border-box;
  width: 150px;
  padding: 10px;
  border: 2px solid #125d92;
}

Wynik

Zadany wymiar 150px obejmuje już padding i border.
