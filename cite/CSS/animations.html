Animacje

W CSS animacje pozwalają ożywić elementy strony. Umożliwiają zmianę wartości właściwości w czasie, tworzenie płynnych efektów i przyciąganie uwagi użytkownika.

Animacje CSS vs przejścia

Przejścia (transition) działają, gdy wartość właściwości zmienia się ręcznie, np. po najechaniu kursorem. Animacje (@keyframes) definiują sekwencję klatek, która odtwarza się automatycznie lub w pętli.

Transformacje

Właściwość transform zmienia położenie, skalę, obrót lub nachylenie elementu. Jest często używana razem z animacjami, ponieważ działa wydajnie i nie przesuwa układu innych elementów.

Typowe transformacje

  • translate(x, y) – przesunięcie elementu w osi X i Y.
  • scale(x, y) – zmiana rozmiaru elementu.
  • rotate(angle) – obrót elementu.
  • skew(x, y) – pochylanie elementu.

Kod

.box {
  width: 120px;
  height: 120px;
  background: #1572B6;
  color: white;
  display: grid;
  place-items: center;
  transform: translateX(0) rotate(0deg);
  animation: moveRotate 4s infinite ease-in-out;
}

@keyframes moveRotate {
  0%   { transform: translateX(0) rotate(0deg); }
  50%  { transform: translateX(120px) rotate(180deg); }
  100% { transform: translateX(0) rotate(360deg); }
}

.box:hover {
  animation-play-state: paused;
}

Podstawowe właściwości animacji

  • animation-name – nazwa animacji zdefiniowanej w @keyframes.
  • animation-duration – czas trwania jednej pętli animacji.
  • animation-timing-function – krzywa przyspieszania, np. ease, linear, ease-in-out.
  • animation-delay – opóźnienie przed rozpoczęciem animacji.
  • animation-iteration-count – liczba powtórzeń lub infinite.
  • animation-direction – kierunek, np. normal, reverse, alternate.
  • animation-fill-mode – jak animacja wpływa na element poza czasem trwania, np. forwards.
  • animation-play-state – kontrola odtwarzania, np. paused lub running.

Ważne uwagi

  • Animacje najlepiej działają na właściwościach transform i opacity, bo przeglądarki mogą je przyspieszać sprzętowo.
  • Unikaj animowania właściwości layoutu, takich jak width, height lub margin, jeśli chcesz płynności.
  • Animacje mogą utrudniać dostępność, więc zawsze rozważ stop lub wyłączanie ich dla użytkowników preferujących redukcję ruchu.

Przykład użycia transform z animacją

Połączenie transform i @keyframes pozwala na płynną zmianę pozycji, obrotu i rozmiaru jednocześnie.

Kod

.dot {
  width: 60px;
  height: 60px;
  border-radius: 50%;
  background: #E34F26;
  animation: bounceScale 2s infinite ease-in-out;
}

@keyframes bounceScale {
  0%   { transform: translateY(0) scale(1); }
  50%  { transform: translateY(-30px) scale(1.2); }
  100% { transform: translateY(0) scale(1); }
}

Wynik

Animacje CSS dają duże możliwości: od prostych efektów hover po całe sekwencje ruchu. Warto zacząć od transform i opacity, a następnie dopasowywać tempo i opóźnienia.
