Podstawy CSS

CSS to język służący do opisu wyglądu stron internetowych. Pozwala oddzielić strukturę HTML od prezentacji, czyli kolorów, czcionek, odstępów i układu elementów.

Do czego służy CSS?

CSS umożliwia kontrolę stylów na stronie: definiowanie kolorów, rozmiarów, marginesów, obramowań oraz położenia elementów. Dzięki CSS strona może być bardziej czytelna, estetyczna i dostosowana do różnych urządzeń.

W jakich formach występuje?

CSS może występować w trzech głównych formach: jako styl wewnętrzny w sekcji <style> w dokumencie HTML, jako styl zewnętrzny w osobnym pliku, lub jako styl wbudowany bezpośrednio w atrybucie elementu. Najlepszą praktyką jest używanie zewnętrznych arkuszy stylów, ponieważ ułatwia to utrzymanie i ponowne wykorzystanie reguł.

Co zawiera arkusz stylów?

Arkusz stylów zawiera reguły CSS. Każda reguła składa się z selektora, który wskazuje elementy HTML, oraz deklaracji opisującej właściwości i wartości, np. kolor tła czy układ w siatce.

W arkuszu można także umieścić zmienne CSS, reguły odpowiadające za responsywność, animacje oraz warunkowe style dla różnych rozmiarów ekranu.

Selektory CSS

Selektory wskazują elementy HTML, które mają otrzymać określone style. Pozwalają wybrać pojedyncze tagi, klasy, identyfikatory, elementy zagnieżdżone oraz elementy pasujące do warunków.

Selektor elementu

Kod

#selector-element p {
  color: #0b3a5c;
}

Wynik

To jest paragraf wybrany przez selektor elementu.

Selektor klasy

Kod

.highlighted {
  font-weight: bold;
}

Wynik

Ten tekst jest wyróżniony przez selektor klasy.

Selektor identyfikatora

Kod

#important {
  background-color: #e8f4ff;
  padding: 0.3rem;
}

Wynik

Styl dotyczy tylko tego elementu z identyfikatorem.

Selektor potomka

Selektor potomka wybiera elementy znajdujące się wewnątrz innych elementów. Na przykład div span wybiera wszystkie <span> wewnątrz <div>.

Kod

#selector-descendant span {
  color: #b83232;
}

Wynik

Tekst w spanie wewnątrz bloku.

Selektor atrybutu

Selekcja po atrybucie pozwala wybrać elementy, które posiadają dany atrybut, lub mają jego konkretne wartości.

Kod

#selector-attr a[href^="https"] {
  text-decoration: underline dotted;
}

Wynik

Bezpieczny link

Pseudoklasy

Pseudoklasy wybierają elementy w określonym stanie, np. :hover dla najechania kursorem lub :first-child dla pierwszego elementu w grupie.

Kod

#selector-pseudo a:hover {
  color: #c0392b;
}

Wynik

Najedź kursorem

Pseudoelementy

Pseudoelementy tworzą wirtualną część w treści, np. element przed lub po zawartości bloku.

Kod

#selector-pseudo-element p::before {
  content: "» ";
  color: #555;
}

Wynik

Ten tekst ma pseudoelement przed sobą.
