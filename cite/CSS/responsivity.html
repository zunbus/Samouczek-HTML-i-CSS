Responsywność

Responsywność to tworzenie stron, które dobrze wyglądają i działają na różnych urządzeniach. Polega na dopasowaniu wyglądu do szerokości ekranu, rozdzielczości i orientacji ekranu.

Podstawowe zasady

  • Używaj elastycznych jednostek, takich jak %, em, rem i vw/vh.
  • Unikaj stałych szerokości, gdy możliwe jest użycie max-width i kontenerów płynnych.
  • Stosuj media queries, aby zmieniać styl przy określonych szerokościach ekranu.
  • Projektuj mobile-first: zaczynaj od małych ekranów i dodawaj zmiany dla większych.

Kod

.box {
  width: 100%;
  max-width: 600px;
  padding: 1rem;
  border: 1px solid #333;
}

@media (min-width: 800px) {
  .box {
    max-width: 800px;
    background: #eef;
  }
}

@media (max-width: 500px) {
  .box {
    padding: 0.5rem;
    font-size: 0.9rem;
  }
}

Wynik

To jest pudełko responsywne. Na małych ekranach dopasowuje się do szerokości i zmniejsza odstępy.

Gdy szerokość ekranu rośnie, kontener może być szerszy, a treść pozostaje czytelna.

Media queries

Media query pozwala zmienić reguły CSS w zależności od rozmiaru ekranu. Najczęściej używane są punkty przerwania dla telefonów, tabletów i komputerów.

Przykładowe punkty przerwania

  • @media (max-width: 600px) – smartfony.
  • @media (min-width: 600px) and (max-width: 900px) – tablety.
  • @media (min-width: 900px) – większe ekrany i desktopy.

Responsywna strona to nie tylko wygląd. To także większa wygoda dla użytkowników i lepsze działanie na urządzeniach mobilnych.
