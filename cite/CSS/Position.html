Pozycjonowanie w CSS

Pozycjonowanie określa, jak element jest umieszczany w dokumencie. W CSS wyróżniamy pięć podstawowych wartości position: static, relative, absolute, fixed i sticky.

Wartości position

  • static – domyślne pozycjonowanie, element układa się normalnie w dokumencie.
  • relative – element pozostaje w układzie dokumentu, ale można go przesunąć względem jego normalnej pozycji.
  • absolute – element jest pozycjonowany względem najbliższego przodka z inną pozycją niż static, lub względem dokumentu, jeśli takiego nie ma.
  • fixed – element jest przyklejony do widoku przeglądarki i nie przesuwa się podczas przewijania strony.
  • sticky – zaczyna jak static, a po przekroczeniu progu przykleja się do górnej lub dolnej krawędzi.

Pozycjonowanie względem rodzica

Jeśli chcesz pozycjonować element względem jego rodzica pozycji, użyj position: relative na elemencie rodzica i position: absolute na pozycjonowanym elemencie, tak jak w przykładzie powyżej.

Najczęstsze zastosowania

  • relative – drobne przesunięcia elementów lub punkt odniesienia dla pozycji absolutnej.
  • absolute – elementy wyciągnięte z normalnego przepływu, np. dymki, tooltipy, układ warstw.
  • fixed – pasek narzędzi, przycisk powrotu do góry, nagłówek widoczny podczas przewijania.
  • sticky – przylegające nagłówki sekcji lub boczne przyciski, które zostają przyklejone na krawędzi widoku.

Pozycjonowanie jest podstawą bardziej zaawansowanych układów CSS. Warto łączyć je z z-index i modelami layoutu, takimi jak flex i grid.
