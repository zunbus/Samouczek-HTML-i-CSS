Formatowanie tekstu

W CSS znajdują się właściwości przeznaczone do kontrolowania wyglądu tekstu. Poniżej zebrano najważniejsze z nich z krótkimi przykładami.

font-style

Określa styl czcionki, np. normal lub italic.

Kod

p { font-style: italic; }

Wynik

To jest tekst pochylony (italic).

font-weight

Określa grubość czcionki (normal, bold, 100–900).

Kod

p { font-weight: 700; }

Wynik

Ten tekst jest pogrubiony (700).

font-family

Określa rodzinę czcionek; można podać listę zapasowych fontów.

Kod

p { font-family: 'Georgia', serif; }

Wynik

Przykład kroju szeryfowego (Georgia).

font-size

Kontroluje rozmiar tekstu; można używać jednostek px, rem, em, % itp.

Kod

p { font-size: 18px; }

Wynik

Tekst o rozmiarze 18px.

text-align

Ustawia wyrównanie tekstu: left, right, center, justify.

Kod

p { text-align: center; }

Wynik

Ten akapit jest wyśrodkowany.

text-decoration

Dodaje dekoracje tekstu: underline, line-through, overline, none.

Kod

a { text-decoration: underline; }

Wynik

Link z podkreśleniem

line-height

Kontroluje wysokość linii i odległość między wierszami tekstu.

Kod

p { line-height: 1.8; }

Wynik

Ten paragraf ma zwiększony odstęp między wierszami, co poprawia czytelność dłuższych tekstów.

letter-spacing

Reguluje odstęp między literami (tracking).

Kod

p { letter-spacing: 0.08em; }

Wynik

Tekst z większym odstępem między literami.

text-transform

Zmienia wielkość liter: uppercase, lowercase, capitalize.

Kod

p { text-transform: uppercase; }

Wynik

Tekst zamieniony na wielkie litery.

white-space

Kontroluje sposób łamania i zachowywania białych znaków (normal, nowrap, pre, pre-wrap).

Kod

p { white-space: pre-wrap; }

Wynik

Linia 1 Linia 2 z zachowaniem spacji
